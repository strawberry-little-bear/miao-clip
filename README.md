# MiaoClip 妙夹

一个面向个人使用的本地优先剪贴板工具箱，把复制到剪贴板的内容变成可以理解、处理和复用的本地信息。

MiaoClip 是一个独立重新实现的项目。它保留剪贴板工具最有价值的基础能力，同时把重点放在更贴近日常工作的内容理解和轻量操作上，而不是复刻 CopyQ 的插件体系，也不是朋友的 `Ctrl-CCCC` 项目的代码分支。

## 为什么做 MiaoClip

复制过的内容经常会变成一次性信息：一段 JSON 需要整理，一个 URL 需要识别，一段文本需要清洁，账号和密码又需要被谨慎地区分开。MiaoClip 希望让这些内容在本机形成一个清晰、可控的工作区：

- 普通剪贴板内容可以被搜索、预览和再次使用
- 内容可以按类型触发合适的下一步动作
- 所有剪贴板历史统一进入收件箱，密码类内容只在显示和通知时遮罩
- 数据优先留在用户自己的设备上
- 功能保持轻量，不要求用户维护复杂的服务端或前端构建链

## 当前版本

当前是 `0.1.0`，用于验证桌面应用的最小闭环：

- 读取当前文本剪贴板
- 将文本写回系统剪贴板
- 识别空文本、普通文本和 JSON
- 格式化 JSON
- 清洁多余空白和换行
- 在本地工作区中查看最近读取的内容
- 将收件箱中的所有历史持久化到 Tauri 应用数据目录
- 应用重启后恢复历史，并自动去重、限制数量
- 按关键词、内容类型和时间范围筛选本地历史
- 支持将内容加入“收藏”，并支持单条删除
- 查看选中内容的类型、长度和预览
- 自动识别文本、URL、账号、密码、图片和文件
- 密码类内容默认遮罩，支持临时显示一次
- 捕获图片后保存本地副本并在详情中预览
- 原生监听器直接驱动独立桌面提示，不依赖主窗口转发
- 通知开关、密码提醒、提示位置和提示框持续时间持久化到本地应用数据目录
- 支持一键暂停监听，以及退出即恢复的隐私模式
- 自动记录复制内容的来源应用、捕获时间、类型、敏感状态和收藏状态
- 使用 macOS 和 Linux 友好的 Tauri 桌面壳

收件箱会写入 Tauri 的应用数据目录，最多保留 100 条去重后的记录。文本历史保存在 `history.json`，剪贴板图片保存在同目录的 `images/`，通知设置保存在 `notifications.json`。疑似密码、Token、API Key、Bearer Token 等内容也会进入收件箱并持久化，但列表、详情和桌面提醒默认只显示遮罩后的安全文案。

## 技术结构

- **桌面壳**：Tauri 2
- **核心逻辑**：Rust
- **系统剪贴板**：`arboard`
- **界面**：原生 HTML、CSS 和 JavaScript
- **前端资源**：直接使用 `ui/` 静态目录

本项目当前不需要 Node.js、npm 或前端打包工具。Tauri 会直接把 `ui/` 作为静态资源打包。后续如果加入更复杂的组件、类型检查或测试工具，再单独评估是否引入 Node.js 构建链；现在不会为了工具链本身增加维护成本。

## 开发环境

需要：

- Rust stable toolchain
- Tauri CLI 2
- 当前操作系统对应的 Tauri WebView 和桌面开发依赖

macOS 通常需要 Xcode Command Line Tools。Linux 需要安装发行版对应的 GTK、WebKitGTK 和开发库；请按 Tauri 官方的 Linux prerequisites 配置。

检查 Rust 与 Cargo：

```bash
rustc --version
cargo --version
```

安装 Tauri CLI（如果本机还没有 `cargo tauri`）：

```bash
cargo install tauri-cli --version '^2'
```

## 启动项目

在仓库根目录执行：

```bash
cargo tauri dev
```

Rust 项目位于 `src-tauri/`，静态界面位于 `ui/`。如果只需要检查 Rust 代码，可以执行：

```bash
cargo check --manifest-path src-tauri/Cargo.toml
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
```

## 本地优先与密码保护策略

MiaoClip 会优先使用本地数据，不要求账号、云端同步或远程服务。当前策略是：

1. 所有剪贴板历史都存放在 Tauri 的应用数据目录中，不依赖云端服务。
2. 疑似密码、Token、API Key、Bearer Token 等内容会被识别为“密码”类别。
3. 密码类别只影响展示、通知和可用操作：默认遮罩，不在桌面提醒中显示原文，也不会进入文本清洁或 JSON 处理结果。
4. “收藏”是用户主动标记的长期关注内容；普通收件箱记录同样会在应用重启后保留。
5. 当前 JSON 文件是本地持久化，不等同于系统级加密存储。后续如需更高安全等级，再接入 macOS Keychain、Linux Secret Service 等系统安全存储。
